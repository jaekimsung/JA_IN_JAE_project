# 주행 환경

자율주행 차량(AV)이 K-CITY 도로망에서 일반 차량(HV)·교통신호와 상호작용하며 정해진 경로를 따라 목적지까지 주행하는 Gymnasium 환경입니다. 구현은 [env/](../kcity/env), 맵 자산은 [maps/kcity/](../maps/kcity/README.md), 환경 계약(`KC-DENSE-v2.1`)은 [configs/kcity/v2_1/](../configs/kcity/v2_1/README.md)에 있습니다.

## 도로와 교통

| 항목 | 내용 |
|---|---|
| 도로망 | CARLA K-CITY OpenDRIVE를 SUMO로 변환. 일반 Edge 176개, 일반 차선 198개, 교차로 내부 차선 346개 |
| 교차로 | 수요 감응식 신호 14곳, 전방향 정지 규칙 2곳, 우선순위 교차로, 회전교차로 |
| 배경 교통 | 네트워크 전체 요청 수요 600대/h(Poisson), Krauss·IDM·EIDM·ACC 4종 동일 비율 |
| 상호작용 교통 | 시나리오마다 정해진 차량 흐름을 사례 seed로 투입(아래 표). 차종과 주행은 배경 교통과 같고 투입 시점·위치만 정함 |
| 평가 수요 | 배경 수요 1.0배(600대/h) |
| warmup | AV 투입 전 60초 동안 교통을 먼저 흘림 |

## 세 가지 주행 과제

도로 구조에서 생기는 상호작용과 AV가 내려야 하는 결정을 과제마다 하나씩 정했습니다. 정의는 [scenarios.json](../configs/kcity/v2_1/scenarios.json)에 있습니다.

| | A. 연속 감응식 신호 통과 | B. 혼잡 속 필수 차선 변경 | C. 비신호 교차로 양보 |
|---|---|---|---|
| 경로 | `-68 → -13 → -71 → -31 → -42 → -77` (약 220m) | `-3#4 → … → -3#8 → -9` (약 120m) | `-77 → -54 → 3#8 → … → 3#4` (약 150m) |
| 도로 구조 | 신호 647·268·764·169가 26~34m 간격으로 연속. 녹색 6~25초 가변 | `-3#4`(68.6m)의 출발 차로는 다음 도로로 이어지지 않고, 옆 차로만 이어짐 | 759에서 우선 도로에 합류, 464에서 비보호 좌회전 |
| 상호작용 차량 | AV 앞 선행 차량 2~4대, 신호 4곳마다 교차 접근로 차량 3~6대. 워밍업 전에 신호의 시작 녹색 현시를 seed별로 정함 | 목표 차로의 앞 선행차·앞차·뒤차 각 1대(첫 관측 때 움직이고 있어야 함)와 통과 차로를 1.5~3초 간격으로 지나가는 5~8대 | 759 우선 도로에 움직이는 선행 차량 2대와 뒤차 1대(첫 관측에서 2대 이상 보여야 함), 이어지는 우선 흐름 4~7대, 464의 교차 흐름 4~6대와 마주 오는 직진 흐름 4~6대. 흐름은 작은 차군과 긴 간격을 번갈아 만듦 |
| 상호작용 | 신호와 대기행렬: 앞차가 적색에 서고, 대기행렬이 다음 교차로까지 밀림 | 통과 차로의 차량 사이 간격 | 교차로로 다가오는 다른 방향 차량과의 교차·합류 |
| AV의 결정 | 적색·황색에서 정지할지 통과할지, 대기행렬 뒤 재출발, 출구가 막힌 교차로에 들어가지 않기 | 어느 간격에 들어갈지, 간격에 맞춰 속도 조절, 간격이 없으면 차로 끝에서 대기 | 우선 차량 앞에 들어갈지 기다릴지, 교차로가 비면 지체 없이 출발 |
| 실패 | 적색 진입, 충돌, 기한 초과 | 경로 이탈, 충돌, 기한 초과 | 충돌, 기한 초과. 우선 차량 앞 진입은 `yield_observation`으로 기록만 하고 종료·감점하지 않음(`priority_gap_observation_only`) |

출발은 A 5m·2m/s, B 30m·3.5m/s, C 5m·3m/s이고 제한 시간은 300초입니다. 학습·수집 사례는 A/A/A/B/B/B/C/C/C/C 순서로 반복합니다. 사례(case)마다 교통·투입 seed가 정해져 있어 같은 사례는 같은 교통으로 재현됩니다.

## 시간과 제어

- 정책은 0.5초마다(2Hz) 행동을 결정하고, SUMO는 0.1초 tick을 5번 진행합니다. 사건이 생기면 1~5 tick 사이에서 끝날 수 있습니다.
- 가속은 `setAcceleration`으로 적용합니다. 정규화 값 +1은 +2.0 m/s², −1은 −4.5 m/s²이고, AV 속도 상한은 8.33 m/s(30km/h)입니다.
- 차선 변경은 1초 동안 요청하며 이후 1초 cooldown이 있습니다.

**SUMO 보조 없음.** AV에는 speedMode 6, laneChangeMode 0을 씁니다. SUMO는 차량의 가감속 한계만 지키고, 그 밖의 판단은 모두 정책이 합니다.

| SUMO가 하는 것 | 정책이 결정 (SUMO가 대신하지 않음) |
|---|---|
| 가감속 한계(+2.0 / −4.5 m/s²) 적용 | 앞차와의 안전 거리 |
| 차선이 없거나 교차로 안·cooldown 중인 차선 요청 거부 | 적색·황색 신호에서 정지 |
| | 비신호 교차로에서 우선 차량에 양보 |
| | 차선 변경 시점과 간격 확인 (요청하면 주변 차량과 상관없이 바로 실행) |

그래서 무조건 가속하는 정책은 A에서 앞차 추돌, B에서 차로 끝 정지 후 기한 초과로 끝납니다. C에서는 양보 위반을 기록만 하므로, 무조건 가속해도 충돌이 없으면 완주합니다(검증 사례 1000~1003 모두 완주). 규칙 전문가는 같은 사례를 모두 완주합니다.

## 관측 (63차원, `[-1, 1]`)

[env/observation.py](../kcity/env/observation.py). 운전자가 직접 보거나 경로 수준의 지도에서 알 수 있는 정보만 넣습니다.
- **넣지 않는 것 (차선 단위 안내):** "어느 차선이 경로로 이어지는지"는 관측에 없습니다. 대신 경로와 무관한 도로 구조인 "현재 차로가 끝나는지"(차로 감소 노면 표시에 해당)를 넣습니다.
- **넣지 않는 것 (우선권 판정):** "어느 차량이 우선권을 가졌는지"도 관측에 없습니다. 교차로 슬롯은 교차로 안 차량과 다른 진입로에서 다가오는 차량을 보여 줄 뿐이고, 양보 여부는 정책이 판단합니다.

| index | 의미 | 쓰이는 결정 |
|---|---|---|
| 0 | AV 속도 / 8.33 | 전체 |
| 1–20 | 주변 차로 5개(왼쪽 2·왼쪽 1·현재·오른쪽 1·오른쪽 2)별 [앞차 간격/100m, 앞차 상대속도, −뒤차 간격/50m, 뒤차 상대속도]. 차가 없으면 (1, 0, −1, 0) | 추종, B의 간격 선택 |
| 21–25 | 차로 존재 여부 | B |
| 26–30 | 차로 점유 밀도(100m 안 차량 수 / 7.5m당) | A의 대기행렬, B |
| 31 | 현재 차로 번호 | B |
| 32 | 남은 경로 거리 / 300m | 전체 |
| 33 | 현재 차로 남은 길이(다음 교차로까지 거리) / 100m | B의 차로 끝, A·C의 정지 위치 |
| 34 | 현재 가속도 | 전체 |
| 35 | 교차로 내부 여부 | 전체 |
| 36 | 차선 변경 cooldown | B |
| 37 | 남은 시간 비율 | 전체 |
| 38 | 100m 안 다음 신호까지 거리 / 100m (없으면 1) | A |
| 39–41 | 다음 신호 적색 / 황색 / 녹색 (각각 한 차원, 없으면 모두 0) | A |
| 42–44 | 경로상 다음 교차로에서 좌회전 / 직진 / 우회전 | C |
| 45 | 양보 표지: 다음 교차로가 비신호이고 AV 진입로가 부도로 | C |
| 46 | 다음 교차로를 지나는 경로 길이 / 50m | A의 출구 막힘, C |
| 47–61 | 교차로 차량 슬롯 3개(교차로 안 차량 먼저, 이어서 예상 도착 시간 순. 같은 진입로에서 출발해 교차로 안에서 갈라진 차량 포함): 존재, 교차로까지 거리/50m, 속도, 교차로 안인지, AV 진행 방향 기준 방위 | C |
| 62 | 현재 차로가 끝남(다음으로 이어지는 연결이 없음). 경로와 무관한 도로 구조 | B |

교차로 차량 슬롯은 AV가 교차로 50m 안에 있을 때, 다른 진입로(상류 50m 포함)와 교차로 안에 있는 차량으로 채웁니다. 정책은 이 63차원만 받습니다. 데이터에는 모든 차량의 절대 위치·속도·차선을 담은 전체 State가 따로 기록됩니다.

## 행동

`[가속, 차선 명령]`, 두 값 모두 [-1, 1]의 연속값입니다. 가속은 m/s²로 변환합니다. 차선 명령은 0.5 이상이면 왼쪽, −0.5 이하면 오른쪽, 그 사이면 유지입니다. 차선이 없거나, 교차로 내부이거나, cooldown 중인 요청은 실행하지 않고 그 이유를 기록합니다.

## 보상

필요한 항만 둡니다. 종료 벌점은 그 Episode에서 더 받을 수 있었던 진행·도착 보상(약 12~32)을 잃는 것과 함께 작용합니다.

| 항목 | 값 | 목적 |
|---|---|---|
| 경로 진행 | 진행 거리(m) / 10 (도착 시 남은 거리 포함) | 목적지를 향해 주행 |
| 도착 | +10 | 완주 |
| 시간 | 결정마다 −0.01 (300초 대기 시 −6) | 불필요한 대기·무한 대기 억제 |
| 충돌 | −20, 종료 | A·B·C 공통: 안전 |
| 적색 신호 진입 | −10, 종료 | A: 신호 준수 |
| 양보 위반 | −10, 종료 | C: 통행 우선권 준수 |

**양보 위반**은 AV가 비신호 교차로에 부도로로 들어가는 순간, 우선권을 가진 차량이 교차로 안에 있거나 3초 안에 교차로에 도착할 거리·속도일 때로 판정합니다. 판정에는 SUMO 교차로 논리를 쓰지만, 이 정보는 관측에 들어가지 않습니다.

## 종료

도착, 충돌, 적색 진입, 양보 위반, 경로 이탈, 텔레포트, 차량 제거, 300초 기한 중 하나가 일어나면 `terminated=True`입니다. 남은 시간이 관측에 들어 있으므로 기한 초과도 종료로 처리합니다. 매 0.1초 tick마다 충돌, 신호 통과(적색 여부), 양보 위반, 실제 차선 변경, 도착, 텔레포트, 경로 이탈을 이벤트로 기록합니다.

## 한계

- 가림·센서 잡음은 모델링하지 않습니다. 교차로 차량 슬롯은 3개이며 교차로 50m 안의 차량만 봅니다.
- 전방향 정지 규칙 준수는 판정하지 않습니다(세 과제의 경로에 없음).
- 실제 K-CITY의 신호 현시와 교통량은 확보하지 못해 가정한 값입니다.
