갱신: 2026-11-16. **아래는 해당 단계 실행 당시의 이력**이다. 현재 현황은 [RESEARCH_STATUS](../../RESEARCH_STATUS.md), 후속 단계는 [RESEARCH_HISTORY](../../RESEARCH_HISTORY.md)를 따른다. 당시 미완료/후속 문구는 현재 미구현을 뜻하지 않는다. 사용자 요청으로 원시 로그·debug 데이터·fixture·source 복사본·로컬 압축본은 삭제했다. 본문에 나온 과거 파일명/경로/SHA는 계보이며 현재 보관 또는 완전 재개를 보장하지 않는다. 필요한 요약·곡선·평가 및 모델11개만 유지하고 새 백업/이동은 하지 않았다.
본 학습이나 추가 optimizer 업데이트 없이 저장된 모델을 검사했다. final 사례는 사용하지 않았다. 확대 평가의 실제 진행 상태와 완료 결과는 아래 실행 경로 및 최종 요약을 따른다.

## 직접 확인한 실패 기전

B2-40k와 B3-30k를 원래 pilot dev 시드의 B/C에서 각각 재현했다. 4개 모두 600결정 동안 차선 유지만 요청했고, 초기 도로 `-3#4_0` 끝에서 기한 초과했다. 그중 568결정, 약284초는 속도0이었다. 가속 요청은 양수였고 왼쪽 기하학적 mask도 허용됐다. 다음 경로로 연결되는 차선은 lane1이다.

별도 진단 개입에서는 같은 모델·시드·가감속 요청을 유지하고, 출발 도로에서 가능한 왼쪽 변경만 요청했다. 4개 모두 도착했다. 이는 초기 필수 차선 선택으로 이4개 실패를 구제한 검사이며, 개입 결과를 원래 정책의 완주 성능에 합산하지 않는다.

[상세 진단](DIAGNOSIS.json) · [원래 지표 재현 일치](REPLAY_CHECK.json)

원래 정책은 왼쪽 확률이0이 아니어도 결정적 argmax에서 유지를 택했다. 마지막 정체 관측에서 B2의 좌/유지 확률은 약0.431~0.463/0.537~0.569, B3는0.272~0.304/0.696~0.728이었다. 마스크가 변경을 막거나 모델이 가속을 요청하지 않은 사례와 구분된다.

## 원인으로 단정하지 않은 후보 요인

- pilot expert10k label은 유지9,936/좌64/우0이다. 필수 변경 사례의 희소성과 평균 모방 loss의 편중은 점검할 후보 요인이다.
- 확률적 PPO 탐색과 결정적 평가의 argmax 차이, 지연 도착 보상의 credit assignment, 공유 trunk 변화 등이 logits 변화에 기여했을 수 있다. 이번 검사로 각 요인의 기여를 분리하지 않았다.
- 보상·마스크·학습률·샘플링을 평가 도중 바꾸지 않았다. 출구 없는 차선을 강제로 mask해 과제를 숨기지 않았다.

B0의90개 feasibility는90회 모두 도착했다. 그러나 후보 기준인 초기HV10대에 미달한 사례가 baseline30회 중8개, 1.5배30회 중1개 있었다. 최소값은5대였다. [교통 노출 원자료](TRAFFIC_EXPOSURE.json)에 기록했으며 낮은 사례를 유리하게 제외하지 않는다. 이 수치는 수업의 공식 숫자 요건이 아니라 팀의 후보 기준이다. 시간가중 실제노출·관측 반경 차량도 함께 검토해 본실험의 수요/warmup/충분성 기준을 확정해야 한다.
