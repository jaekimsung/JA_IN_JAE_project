# K-CITY 로컬 대시보드

저장소 루트에서 다음 명령을 실행하고 브라우저에서 [대시보드](http://localhost:8765)를 엽니다.

```bash
python3 dashboard/server.py
```

Python 3.9 이상에서 표준 라이브러리로 실행합니다. 포트는 `--port 8766`으로 바꿀 수 있습니다. 서버는 루프백 주소에만 바인딩합니다.

- **모델 성능**은 같은 패널 이름, 케이스 UID 집합, 지표 버전의 평가를 모읍니다. 별도 저장된 정책 평가와 RL 예산 종료 체크포인트를 표시합니다. seed별 값과 seed 간 표본 표준편차를 확인할 수 있습니다.
- **학습 과정**은 각 실행의 `curve.jsonl`과 RL의 `dev/T*/SUMMARY.json`을 읽습니다. BC의 가로축은 업데이트 수, RL의 가로축은 전이 수입니다. 점에 마우스를 올리면 해당 값을 볼 수 있습니다. 그래프 저장 버튼으로 선택한 곡선을 SVG로 내려받습니다.
- **주행 분석**은 에피소드별 시나리오와 종료 원인, 차선 변경 위치와 대기 시간을 표시합니다. 같은 에피소드가 부모 평가와 수요별 폴더에 중복 저장된 경우 한 번만 표시합니다.
- **데이터와 로그**는 데이터 풀의 전이 수와 분할, 데모 실행 상태, 선택한 로그의 최근 32 KiB를 표시합니다. 전체 로그는 표시된 경로의 `runs/` 아래 파일에서 확인할 수 있습니다.

페이지가 열려 있고 자동 갱신이 켜져 있으면 30초마다 결과를 다시 읽습니다. 학습 프로세스와 독립적으로 작동하며 모델이나 전이 파일을 로드할 필요가 없습니다.

서버 실행 후 터미널에 뜨는 http://localhost:8765 를 ctrl+클릭 하면 창이 열립니다.
