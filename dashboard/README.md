# K-CITY 로컬 대시보드

저장소 루트에서 다음 명령을 실행하고 브라우저에서 [대시보드](http://localhost:4796)를 엽니다.

```bash
python3 dashboard/server.py
```

Python 3.9 이상에서 표준 라이브러리로 실행합니다. 포트는 `--port 8766`으로 바꿀 수 있습니다. 서버는 루프백 주소에만 바인딩합니다.

- **모델 성능**은 같은 패널 이름, 케이스 UID 집합, 지표 버전의 평가를 모읍니다. 별도 저장된 정책 평가와 RL 예산 종료 체크포인트를 표시합니다. seed별 값과 seed 간 표본 표준편차를 확인할 수 있습니다.
- **학습 과정**은 각 실행의 `curve.jsonl`과 RL의 `dev/T*/SUMMARY.json`을 읽습니다. BC의 가로축은 업데이트 수, RL의 가로축은 전이 수입니다. 점에 마우스를 올리면 해당 값을 볼 수 있습니다. 그래프 저장 버튼으로 선택한 곡선을 SVG로 내려받습니다.
- **학습 방법별 충돌률 비교**는 선택한 학습 버전과 시드의 BC·SAC·RLPD를 같은 패널·케이스·지표 버전에서 한 그래프에 표시합니다. SAC·RLPD는 환경 전이별 평가 곡선이고, BC는 선택된 모델의 고정 충돌률 점선입니다. 무효·미완료 평가와 복수 실행의 혼합은 제외하며, 표에서 최신 평가의 충돌 수와 분모를 확인할 수 있습니다. 그래프 저장 버튼으로 SVG를 내려받습니다.
- **주행 분석**은 에피소드별 시나리오와 종료 원인, 차선 변경 위치와 대기 시간을 표시합니다. 같은 에피소드가 부모 평가와 수요별 폴더에 중복 저장된 경우 한 번만 표시합니다.
- **데이터와 로그**는 데이터 풀의 전이 수와 분할, 데모 실행 상태, 선택한 로그의 최근 32 KiB를 표시합니다. 전체 로그는 표시된 경로의 `runs/` 아래 파일에서 확인할 수 있습니다.

본 학습 출력 경로는 `runs/dense_v2_1_main/`이며, 학습 전에는 B0 Expert로 세 시나리오를 재생할 수 있습니다.

페이지가 열려 있고 자동 갱신이 켜져 있으면 30초마다 결과를 다시 읽습니다. 학습 프로세스와 독립적으로 작동하며 모델이나 전이 파일을 로드할 필요가 없습니다.

서버 실행 후 터미널에 뜨는 http://localhost:4796 를 ctrl+클릭 하면 창이 열립니다.

### SUMO GUI 반복 주행

**SUMO 주행**에서 모델(학습 seed 포함)과 시나리오를 선택하고 **SUMO GUI 실행**을 누릅니다. 서버를 실행한 데스크톱에서 v2.1 검증 사례(A 1000, B 1005, C 1004)를 기본 교통량, 1배속으로 반복합니다. SUMO 창을 닫으면 해당 주행이 끝납니다. 같은 조합을 다시 누르면 이미 실행 중인 창의 상태를 표시합니다.

**A → B → C · 한 차량으로 연속 주행**은 케이스 1000에서 같은 차량이 세 구간을 연결도로로 이어 달립니다. A의 신호 구간을 지난 뒤, B에 진입하면 데모가 차량을 끝나는 차로로 유도하고 선택한 정책이 본선 합류를 결정합니다. C 접근 시 우선 교통이 투입되며 C 종점이 한 회차의 목적지입니다.

**B → A → C · 한 차량으로 연속 주행**은 B의 차선 변경으로 출발해 A의 연속 신호를 통과하고 C의 양보 교차로를 거쳐 도착합니다.

GUI에서는 B0 Expert, 기존 v1 학습 선택한 학습 버전과 시드의 BC·SAC·RLPD, 체크포인트가 준비된 v2.1 본 학습 모델을 선택할 수 있습니다. 모든 모델은 v2.1에서 주행합니다. BC는 최저 검증 손실, SAC와 RLPD는 예산 종료 체크포인트를 사용합니다. 표와 그래프만 복사한 저장소에서는 학습 모델의 체크포인트도 해당 실행 폴더에 복원해야 합니다.

GUI 실행에는 프로젝트의 SUMO와 학습용 Python 환경이 필요합니다. 시스템 Python에 학습 패키지가 없으면 데모 실행기가 저장소의 가상환경과 이 컴퓨터의 K-CITY 학습용 캐시 가상환경을 차례로 확인합니다. 직접 선택하려면 가상환경에서 서버를 실행하거나, 서버 명령에 `--demo-python /경로/venv/bin/python`을 추가해 데모용 인터프리터를 지정하세요. 대시보드로 시작한 데모는 현재 상태를 메모리로 전달하며 `STATUS.json`을 생성하지 않습니다. 터미널 로그는 `runs/dense_v2_1_main/demo/`에 저장됩니다.

ABC 연속 주행은 출발 시 전용 선행 차량을 15 m 앞에 배치합니다. 선행 차량은 SUMO 신호·충돌 안전 규칙을 따르며 자차와의 간격에 맞춰 속도를 조절합니다. B 합류 구간과 마지막 신호 이후에는 속도 조절을 해제해 교차로 통행을 이어갑니다. 이 구성은 대시보드 시연용입니다.
